# 시계 재고 모니터

ATOWAK 및 ZEROO TIME 글로벌 공식몰의 상품과 옵션별 주문 가능 여부를 조회합니다. 공식 브랜드와 제휴하지 않은 프로젝트입니다.

## 로컬 실행

Node.js 20 이상이 필요합니다. 의존성 설치 없이 아래 명령을 실행하고 터미널에 표시되는 주소를 브라우저에서 엽니다.

```sh
node dashboard.mjs
```

## 웹 배포

`worker/index.js`를 Fetch API와 ES 모듈을 지원하는 Worker 런타임의 진입점으로 사용합니다. `/`는 대시보드를, `/api/stock`은 각 공식몰의 재고 데이터를 반환합니다. 별도의 API 키가 필요하지 않습니다.

브라우저 탭이 표시되는 동안 5분 간격으로 재조회합니다. 서버는 성공한 응답을 1분간 재사용합니다. 주문 및 배송 조건은 각 상품의 공식 페이지를 확인하세요.

소스 코드는 MIT 라이선스를 따릅니다. 상품 이미지와 브랜드 표시는 해당 권리자에게 귀속됩니다.
